# Security policy

Do not disclose suspected vulnerabilities in a public issue. Report them privately through [GitHub's private vulnerability reporting](https://github.com/benjamin-small/homework-helper/security/advisories/new). Include reproduction steps, affected versions, and potential impact.

Include browser/device details and a minimal example with synthetic data; do not attach learner identities, grades, or private photos. The app stores progress in the visitor's browser and uses browser/system speech synthesis, which may call a remote voice service. See README.md for those boundaries.

Only the latest main revision and its current GitHub Pages deployment receive security fixes. Older snapshots and tags are not maintained separately. The maintainer, @benjamin-small, will acknowledge a complete report as soon as practical and coordinate remediation and disclosure with the reporter; no fixed response time is promised.
